## ✨ Features

- **Modern Design**: Clean, minimalist interface with smooth animations and transitions
- **Responsive Layout**: Fully responsive design that works seamlessly across all devices
- **Interactive Cursor Glow**: Custom cursor effect that enhances user experience on desktop
- **Dark Mode Ready**: Built with dark mode support using next-themes
- **Performance Optimized**: Fast page loads and optimized images with Next.js Image component
- **Accessible**: Semantic HTML and ARIA labels for better accessibility
- **SEO Friendly**: Optimized meta tags and structured data

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm, yarn, or pnpm package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Camilo-Suarez98/camilo-suarez-portfolio.git
cd camilo-suarez-portfolio
```

2. Install dependencies:
```bash
npm install
# or
yarn install
# or
pnpm install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## 📝 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint

## 🎨 Customization

### Update Personal Information

1. **Bio & About**: Edit `components/bio-description.tsx`
2. **Experience**: Update `lib/experiences.ts`
3. **Projects**: Update `lib/projects.ts`
4. **Social Links**: Modify `components/social-links.tsx`
5. **Resume Link**: Update the Google Drive link in `components/experiences-section.tsx` and `app/page.tsx`

### Styling

- Global styles: `app/globals.css`
- Tailwind config: `tailwind.config.ts`
- Component styles: Inline Tailwind classes
